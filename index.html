Hubungkan database dulu

Login dan favorit butuh database. Isi config.js di repo Anda dengan alamat dan kunci Supabase, lalu muat ulang halaman ini.

  1. Buat proyek gratis di supabase.com.
  2. Buka SQL Editor, tempel isi supabase-setup.sql, lalu tekan Run.
  3. Salin Project URL dan anon public key dari Project Settings → API ke config.js.
  4. Di Authentication → URL Configuration, isi Site URL dengan alamat situs ini.
